# Woody - Blog Website with Django

Woody is a full-featured blog website built with Django. It includes user authentication (login/register), post management, and responsive design using SCSS.

## Features
- User registration and login
- Blog post creation, editing, and deletion
- Custom HTML templates
- Responsive design with SCSS
- Organized project structure

## Technologies Used
- Python (Django)
- HTML5, CSS3, SCSS
- JavaScript
